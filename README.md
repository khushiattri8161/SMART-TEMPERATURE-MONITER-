# 🌡️ Smart Temperature Monitoring System using ESP32

## 📌 Overview
The Smart Temperature Monitoring System is an IoT-based embedded systems
project developed using ESP32, a DHT11 temperature and humidity sensor,
and the Blynk IoT platform.

The system measures environmental temperature and humidity and displays
the readings on a mobile dashboard through Wi-Fi. It can also generate
alerts when the temperature crosses a predefined threshold.

## 🛠️ Components Used
- ESP32 Development Board
- DHT11 Temperature and Humidity Sensor
- Buzzer (optional)
- Jumper Wires
- Breadboard
- Blynk IoT Platform

## ⚙️ Features
- Real-time temperature monitoring
- Humidity measurement
- Remote monitoring through Blynk
- Threshold-based temperature alerts
- Optional buzzer for high-temperature warnings

## 🔄 Working Principle
1. The DHT11 sensor measures the surrounding temperature and humidity.
2. The ESP32 reads and processes the sensor data.
3. The ESP32 connects to Wi-Fi and sends the readings to Blynk.
4. The values are displayed on the mobile dashboard.
5. An alert is triggered when the temperature reaches the configured
   threshold.
